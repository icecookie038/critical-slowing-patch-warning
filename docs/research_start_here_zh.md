# 科研工作入口

本仓库的新方向是：从不规则时间间隔的栅格观测，研究质量信息和空间表征能否改善生态恢复事件预测。当前已完成第一阶段原型和盐沼先导试验，尚未证明新模型具有稳定优势。

## 材料放在哪里

- **GitHub**：保存代码、实验方案、数据来源、依赖、测试、必要的小型结果和论文论据。具体版本以提交编号为准。
- **ChatGPT 云端项目“临界慢化”**：用于讨论、探索和审稿式质疑。讨论达成的决定需要落入仓库文档，不能只依赖聊天记忆。
- **本地数据目录**：存放原始数据、处理后的栅格和模型权重；这些大文件不进入 Git。通过来源地址、校验值和处理脚本关联。
- **论文写作**：方法对应代码，数字对应固定运行，结论对应结果文件。未完成的验证写成限制与后续工作。

## 当前可以直接使用

从 [README-QIR](../README-QIR.md) 安装依赖、运行测试及小型示例；实际数据的处理命令见 [阶段方案](qir_event_phase1.md)。

[试验记录](../results_summary/qir_phase1/REPORT.md) 汇总了 230 个损失事件、676 条风险区间的双向盐沼先导试验。完整指标、事件清单、预测和运行信息位于同目录的 `marsh/`。请同时阅读数据历史可用性和小样本限制。

[来源登记](qir_sources.md) 用于论文、公开数据和开源包检索；登记许可证、输入要求及适用性，确认后再引入依赖。现阶段没有已验证的第二个独立生态系统。
