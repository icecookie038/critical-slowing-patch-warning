# Critical-slowing project version history

The current `seir/` directory contains the reviewed v3.7 recovery snapshot.
The [history branch](https://github.com/icecookie038/critical-slowing-patch-warning/tree/seir-history/v1.0-v3.7)
preserves 71 source commits from the earlier research repository. Its three
historical CSV result files use relative run directories in place of one
machine-specific absolute prefix; the metric values were not changed.

The identifiable version checkpoints are:

- [v1.0](https://github.com/icecookie038/critical-slowing-patch-warning/tree/cc32bc21c924edd887d846424f49bf563a6ac68f): traditional early-warning baseline comparison.
- [v1.1](https://github.com/icecookie038/critical-slowing-patch-warning/tree/5939145c8db516e9a00816302b02347602547902): lead-time proxy and feature-importance analysis.
- [v1.2](https://github.com/icecookie038/critical-slowing-patch-warning/tree/cb045e76e7144742f7f87941c7d04a32c2dd42d4): first-alarm and CNN-GRU results.
- [v1.3](https://github.com/icecookie038/critical-slowing-patch-warning/tree/a989271cc8ab91fed1af9192f1df453a1848df43): prepatch indicators and conservative feature analysis.
- [v1.4](https://github.com/icecookie038/critical-slowing-patch-warning/tree/8d9dc5d52efbedebc56a708ac7fbfee4447dc0fb): PWSI index and robustness summary.
- [v2.0](https://github.com/icecookie038/critical-slowing-patch-warning/tree/25f7d7a0d001b8c76a6a8f7f1cf9badd923f29c0): synthetic vegetation cross-system validation.
- [v2.2](https://github.com/icecookie038/critical-slowing-patch-warning/tree/1f37e1e3b2e5d4fe3127370deb5547a3f3771c47): synthetic robustness and correlation-threshold sensitivity.
- [v2.3](https://github.com/icecookie038/critical-slowing-patch-warning/tree/f1c2c47302473e2c8d181850dfe68a5cc328e615): patch-formation process analysis.
- [v2.4](https://github.com/icecookie038/critical-slowing-patch-warning/tree/6824e8afa9154cc3fff9b26f12125ca4433e711d): integrated patch-dynamics validation.
- [v2.5](https://github.com/icecookie038/critical-slowing-patch-warning/tree/7ffb455e7345d223a1ce8a0c25f415dfb5d44840): spatial-shuffle controls.
- [v2.6](https://github.com/icecookie038/critical-slowing-patch-warning/tree/e6f143945c21cc0b91aa0220ecacd4d282edaed5): patch-formation summary and manuscript material.
- [v2.7](https://github.com/icecookie038/critical-slowing-patch-warning/tree/0d0f518d922ed0f443405fc67fda80338dd597c6): results draft.
- [v2.8](https://github.com/icecookie038/critical-slowing-patch-warning/tree/8779567f81598d9307e51e9c48ebf2631fa15b03): patch-formation dynamics analyses and summary.
- [v2.9](https://github.com/icecookie038/critical-slowing-patch-warning/tree/65c22fbb1459b41a4efbc69d99354ad60e859588): manuscript integration.
- [v3.5–v3.7 recovered snapshot](https://github.com/icecookie038/critical-slowing-patch-warning/tree/5315b3bbdbfe9d8561f911bf5ec53ad72a1e0aa4): direct ecological recovery, published-data precision benchmark, and time-safe event-level survival analysis.

The [v2.0 summary](docs/v2_0_vegetation_ca_summary.md) describes v2.1 as a
**proposed next step** involving remote-sensing or pine-wilt-disease data. No
separate v2.1 implementation or source snapshot is present in the recovered
branches. There are likewise no separately verified v3.0–v3.4 source
snapshots. The v3.5–v3.7 material was recovered in one commit
from files that had been untracked in the earlier working tree. See
[`docs/RECOVERY_v3_7_2026-09-05.md`](docs/RECOVERY_v3_7_2026-09-05.md) for
provenance and limits. Version links point to commits on the reviewed history
branch.

The public history excludes the separate 2026 modeling Problem B question 3
and question 4 material.
